ERPNext

Uses your regular login credentials — no API key needed

1
Find Your ERPNext URL
Your ERPNext URL is what you type in the browser to access it — e.g. https://yourcompany.erpnext.com or a self-hosted address like https://erp.yourcompany.com.
2
Use Your Login Credentials
Enter the same username (email) and password you use to log into ERPNext daily. The tool logs in using the same session method as your browser.
3
Enter All Three Fields
Paste the ERPNext URL, username, and password into the three fields shown after selecting ERPNext in the tool.
🔒 Your ERPNext permissions are fully respected.
This tool logs in as you — exactly like opening ERPNext in a browser tab. It can only access data your account is allowed to see. Nothing is bypassed, no special admin access is needed. If you can see a report inside ERPNext, this tool can extract it. If you can't, it won't show up here either.

Works with any ERPNext login — no API key or admin rights required.
Security: Your credentials are sent directly to your ERPNext server over HTTPS. They are never stored on our servers — used once to authenticate and fetch your data, then discarded immediately.

Odoo

Uses your regular Odoo login — no API key needed

1
Find Your Odoo URL
Your Odoo URL is what you type in the browser to open Odoo — e.g. https://yourcompany.odoo.com or a self-hosted address like https://odoo.yourcompany.com.
2
Enter Your Login Credentials
Enter the same email and password you use to log into Odoo daily. You also need to enter your database name — this is shown on the Odoo login page or in your URL path.
3
Find Your Database Name
On the Odoo login screen, the database name appears as a dropdown or pre-filled field. If your URL is https://acme.odoo.com/web, your database name is usually acme. For self-hosted Odoo, ask your admin if unsure.
4
Select Your Report
After entering credentials, select Full CRM Report to generate all 13 sheets — Pipeline, Stage Analysis, Salesperson, Customer-wise, Monthly Trend, 🔮 Forecast, ⏱️ Deal Velocity, Leads, Contacts, Activities, Won & Lost, Raw Data, and Dashboard.
🔒 Your Odoo permissions are fully respected.
The tool authenticates as you using Odoo's standard JSON-RPC login — the same method Odoo's own web interface uses. It can only access data your account is permitted to see. No admin rights required.

13 sheets generated: Dashboard · Pipeline · Stage Analysis · Salesperson · Customer-wise · Monthly Trend · 🔮 Forecast · ⏱️ Deal Velocity · Leads · Contacts · Activities · Won & Lost · Raw Data.
Security: Your credentials are sent directly to your Odoo server over HTTPS. They are never stored on our servers — used once to authenticate and fetch your data, then discarded immediately.
